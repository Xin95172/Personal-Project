  - 行政
  - 民事

  - Majority Class baseline
- **錯誤分析：**
  - 混淆矩陣
  - 各類別 Precision / Recall / F1-score

#### 本節應寫成第四章導言

說明本章不是單純報分數，而是回答以下問題：

1. MNIR+SVM 核心流程本身表現如何？
2. Direct SVM 對照流程是否具有競爭力？
3. MNIR 特徵轉換是否相較 Direct SVM 帶來額外增益？
4. BoW、TF、TF-IDF 在不同案件類型下是否有不同表現？
5. 移除 outcome leakage 後模型是否仍維持分類能力？
6. 模型錯誤主要集中在哪些類別？
#### 可使用段落

本章依據第三章之模型流程，分別針對行政、民事、刑事與刑事附帶民事四類案件進行模型評估。本文以 Chi-square + MNIR + SVM 作為核心技術流程，目的在於檢驗 MNIR 監督式特徵轉換是否能將高維法律文本特徵轉換為更具判別力之低維表示。為判斷 MNIR 轉換是否具有額外增益，本文另設置 Chi-square + Direct SVM 作為對照流程。

由於本研究資料具有明顯類別不平衡，Accuracy 可能受到多數類別影響，因此本章以 Macro F1 作為主要評估指標，並輔以 Accuracy、Majority Class baseline、混淆矩陣與分類報告進行分析。整體而言，本章將依序檢視核心流程表現、對照流程表現、MNIR 轉換是否帶來增益、不同文字特徵表示之差異、outcome leakage 之影響，以及模型在不同裁判結果類別上的錯誤型態。

#### 段落方向

**請說明：**

- 比較兩種流程在各資料集之 Macro F1。
- 哪些資料集 MNIR+SVM 較佳。
- 哪些資料集 Direct SVM 較佳。
- 哪些資料集兩者差異有限。
- 若 MNIR+SVM 較佳，解釋 MNIR 可能帶來的增益。
- 若 Direct SVM 較佳，解釋卡方篩選後稀疏詞彙特徵可能已保留足夠訊息。
- 若差異很小，解釋為 MNIR 未呈現明顯穩定增益。
#### 中性分析模板

請依實際數據選擇合適寫法。

**若 MNIR+SVM 較佳：**
若 MNIR+SVM 的 Macro F1 高於 Direct SVM，表示在該資料集或特徵設定下，MNIR 特徵轉換可能有助於將高維文本特徵壓縮為較具判別力的低維表示，進而改善 SVM 分類表現。
**若 Direct SVM 較佳：**
若 Direct SVM 的 Macro F1 高於 MNIR+SVM，表示在該資料集或設定下，卡方特徵選擇後的原始稀疏詞彙特徵可能已保留足夠分類訊息，進一步 MNIR 轉換未必能提升模型表現。
**若兩者差異有限：**
若兩者 Macro F1 差異有限，表示 MNIR 特徵轉換在該資料集下未呈現明顯穩定增益，後續仍需透過更多資料切分或外部資料驗證其穩定性。
#### 重要口徑

不能寫：

MNIR 無效。

應寫：

在本研究資料、標籤設定與超參數範圍下，MNIR+SVM 是否具有增益需依各資料集實際結果判斷。
#### 可使用段落

表 4-3 比較 Chi-square + MNIR + SVM 與 Chi-square + Direct SVM 在各資料集中的 Macro F1。此比較的目的，是檢驗 MNIR 特徵轉換是否能在卡方特徵選擇後進一步改善分類效果。若 MNIR+SVM 的 Macro F1 高於 Direct SVM，表示 MNIR 可能成功保留並壓縮與裁判結果相關的詞彙分布訊號；若 Direct SVM 較高，則表示原始稀疏詞彙特徵在經過卡方篩選後已具備足夠分類能力，進一步轉換未必能帶來增益。

因此，本節的重點不是預設任一流程必然較佳，而是依據實證結果判斷 MNIR 特徵轉換在不同案件類型下是否具有額外價值。
