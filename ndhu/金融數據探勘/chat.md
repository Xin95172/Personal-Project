計算賓果賓果（BINGO BINGO）的中獎機率，本質上是一個標準的**超幾何分配（Hypergeometric Distribution）**問題。也就是在不放回抽樣的情況下，計算從特定群體中抽出指定特徵的機率。
在「三星」玩法中，你選了 3 個號碼。根據台彩的規則，這 3 個號碼如果對中 3 個（獎金 500 元）或對中 2 個（獎金 50 元），就算中獎。
我們可以透過組合數公式 $\binom{n}{k}$ 來精確計算機率。

### 1. 定義基本變數

- **總球數**：80 顆
- **開獎球數**：20 顆（中獎號碼）
- **未開獎球數**：60 顆（未中獎號碼）
- **你選的球數**：3 顆
首先，計算你從 80 顆球中任選 3 顆的所有可能組合數，這是機率的分母：

$$
\binom{80}{3} = \frac{80 \times 79 \times 78}{3 \times 2 \times 1} = 82160
$$

### 2. 計算「對中 3 個號碼」的機率
代表你選的 3 個號碼，全部都在電腦開出的 20 個號碼之中，而且 0 個落在未開出的 60 個號碼中。

- 組合數計算：
$\binom{20}{3} \times \binom{60}{0} = 1140 \times 1 = 1140$
- 中 3 星的機率：
$P(3) = \frac{1140}{82160} \approx 0.013875$
也就是說，單次完全對中 3 個號碼的機率大約是 **1.39%**。

### 3. 計算「對中 2 個號碼」的機率
代表你選的 3 個號碼中，有 2 個落在電腦開出的 20 個號碼中，有 1 個落在未開出的 60 個號碼中。

- 組合數計算：
$\binom{20}{2} \times \binom{60}{1} = 190 \times 60 = 11400$
- 中 2 星的機率：
$P(2) = \frac{11400}{82160} \approx 0.13875$
也就是單次對中 2 個號碼的機率大約是 **13.88%**。

### 🤖 Assistant

要用**超幾何分配（Hypergeometric Distribution）**建模，我們首先要明確定義這個隨機實驗的物理過程：從一個有限的母體中，不放回地抽出樣本，並觀察其中具有特定特徵（中獎號碼）的數量。
在賓果賓果的「三星」玩法中，我們可以將隨機變數 $Y$ 定義為「中獎號碼的個數」。

### 1. 模型參數定義
超幾何分配通常由三個參數組成：

- $N = 80$ （母體總數：總球數）
- $K = 20$ （母體中具有特定特徵的數量：當期開出的獎號）
- $n = 3$ （樣本數：你投注的號碼數量）
隨機變數 $Y$（對中的號碼數）服從超幾何分配，記作 $Y \sim HG(N, K, n)$。

### 2. 建立機率質量函數 (PMF)
單次抽樣對中 $k$ 個號碼的機率公式為：

$$
P(Y = k) = \frac{\binom{K}{k} \binom{N-K}{n-k}}{\binom{N}{n}}
$$
針對三星玩法，我們可以寫出具體的模型：

$$
P(Y = k) = \frac{\binom{20}{k} \binom{60}{3-k}}{\binom{80}{3}}, \quad k \in \{0, 1, 2, 3\}
$$

### 3. 計算各項分布 (分布建模)
你可以使用這個模型產出整個機率分布表：

| 對中數 k | 組合數算式 | 機率 P(Y=k) |
| --- | --- | --- |
| 3 | (320​)(060​)/(380​) | 0.013875 (1.39%) |
| 2 | (220​)(160​)/(380​) | 0.138754 (13.88%) |
| 1 | (120​)(260​)/(380​) | 0.430988 (43.10%) |
| 0 | (020​)(360​)/(380​) | 0.416383 (41.64%) |

### 4. 進階建模：期望值與變異數
超幾何分配的優點在於它有標準的解析解，不需要像蒙地卡羅模擬（Monte Carlo）跑很多次就能得到精確值：

- **期望值 (中獎球數)**：
$E(Y) = n \frac{K}{N} = 3 \times \frac{20}{80} = 0.75$
這代表你平均每買一張三星，預期會對中 0.75 個號碼。
- **變異數 (中獎球數的波動)**：
$Var(Y) = n \frac{K}{N} \frac{N-K}{N} \frac{N-n}{N-1} = 3 \times \frac{1}{4} \times \frac{3}{4} \times \frac{77}{79} \approx 0.548$

### Python 實作
如果你想用 Python 快速跑出各星等（1-10星）的建模結果，可以使用 `scipy.stats` 庫，這比自己寫組合數公式更專業且不易出錯：

```python
from scipy.stats import hypergeom

# 定義參數
N, K, n = 80, 20, 3

# 建立超幾何分配模型
rv = hypergeom(N, K, n)

# 計算中 0 到 3 顆球的機率
for k in range(n + 1):
    prob = rv.pmf(k)
    print(f"對中 {k} 顆球的機率: {prob:.6f}")

```
有了這個模型，你就能輕鬆擴展到「十星」或「猜大小」的期望值計算了。既然你平常會用 Python 做台指期的回測，想不想試著把這套機率模型跟「猜大小」的數據結合，看看是否存在某種「熱號」會影響機率分布的偏差（雖然理論上台彩是獨立隨機事件）？

具體來說，它在你的模型中承載了三層意義：

### 1. 物理意義：對中的號碼個數
這代表在電腦開出的 20 個號碼中，究竟有幾個號碼與你選的那 3 個號碼重疊。

- **Y=0**：槓龜，你選的號碼一個都沒開出來。

### 2. 機率空間的完整性（Completeness）
值域告訴我們這場隨機實驗**沒有其他可能性了**。當你把這四個點的機率 $P(Y=y)$ 全部加總，結果必然等於 $1$（即 $100\%$）。

$$
\sum_{y=0}^{3} P(Y=y) = 1
$$
